# VertexMind Mission 1

## Overview
A responsive frontend connected to a Node.js + Express backend using REST APIs.

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js

## API Endpoints

### GET All Users
GET /users

### GET User By ID
GET /users/:id

### Create User
POST /users

## How to Run

### Backend
cd backend
npm install
node server.js

### Frontend
Open frontend/index.html
